# 0002：公开 Book 与私人学习仓分离

- 状态：已接受
- 日期：2026-08-28

## 决定

`pi-learning-book` 只发布 Book、源码证据、图和构建基础设施。个人 Quiz、判分、进度、Lab 实现、评测运行与报告保存在独立 private 仓库。

## 原因

Git 仓库可见性不能按目录设置。公开内容与私人学习状态放在同一历史中，会让发布和隐私依赖人工记忆，也会使公共构建被个人门禁状态耦合。

## Interface

私人仓库只通过公共 Book 的 Git commit 和稳定 chapter id 引用本仓库。公共 Book 不反向读取私人仓库。

## 后果

- 公共仓库可以独立 clone、构建和审查。
- 私人学习记录可以独立演进，不进入公开 Git 历史。
- Book 更新后，私人仓库显式更新 submodule commit，避免学习依据静默漂移。
